# Jeevan Mitra – AI-Powered Blood Donation & Emergency Response Platform

## Overview

Jeevan Mitra is a web-based platform designed to connect blood donors with hospitals during emergencies. The system helps hospitals quickly find eligible donors based on blood group and location, reducing the time required to arrange blood during critical situations.

**Tagline:** Every Drop Saves a Life

---

## Problem Statement

Finding blood donors during emergencies is often difficult and time-consuming. Hospitals struggle to reach suitable donors quickly, which can lead to delays in treatment.

Jeevan Mitra solves this problem by providing real-time donor matching and emergency notifications.

## Installation Steps

### Clone Repository

```bash
git clone https://github.com/manojga56565/Jeevan-Mitra.git
```

### Navigate to Project Folder

```bash
cd Jeevan-Mitra
```

### Install Dependencies

```bash

```

### Start Application

```bash
npm start
```
